# 淘宝商品详情页（站点知识文档）

> 这类文档会被 agent 读取，用来告诉模型"这个后台页面怎么用"。ecclaw 的平台包把
> dabi 的 `docs/tx/<平台>/<页面>.md` 约定沿用下来。

## 页面识别
- URL 形如 `https://item.taobao.com/item.htm?id=<商品ID>`
- 天猫：`https://detail.tmall.com/item.htm?id=<商品ID>`

## 关键元素
| 元素 | 位置 | 说明 |
|---|---|---|
| 标题 | `.tb-main-title` | 商品主标题 |
| 价格 | `.tb-rmb-num` / `.tb-price` | 当前售价，促销时以到手价为准 |
| SKU 规格 | `.tb-sku` 区域 | 颜色/尺码等组合 |
| 库存 | `.tb-stock` | 剩余可售数量 |
| 销量 | `.tb-sell-counter` | 累计或月销量 |

## 操作注意
1. 详情页可能按登录态返回不同价格，取价前先确认是否已登录目标店铺买家账号。
2. SKU 是笛卡尔积：规格组合在 `.tb-sku` 内联动，不要假设可任意组合下单。
3. 商品下架或被处罚时页面会跳转到提示页，调用工具前需判断页面类型。
